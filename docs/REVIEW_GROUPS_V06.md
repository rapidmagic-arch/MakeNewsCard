# MakeNewsCard v0.6 — 기사 검토 작업대와 추천 그룹 설정

## UX
- 기사 목록과 선택 기사 상세 편집을 한 작업대에서 처리. 데스크톱은 우측 고정형 상세 패널, 1060px 이하에서는 목록을 유지한 채 우측 슬라이드 패널 사용. 닫기·배경 클릭·Escape로 돌아오며 미저장 편집 확인 유지.
- 검토 화면 상단에서 `추천 그룹 설정` 또는 `출력 미리보기`로 바로 이동. TOP 카드 선정·순서는 접이식 보조 영역에 보존.
- 추천/추가 검토/그 외/수록/전체 대기열은 그대로 유지하며, `추천 그룹` 필터와 그룹별 후보 건수 칩을 추가.

## 추천 그룹 설정
- 환경설정에서 사용자 지정 그룹을 추가·수정·삭제. 필드: 이름, 키워드, 수록 추천 후보 여부, **고정된** 발행 섹션(정책/시장/글로벌/연구개발).
- 설정은 로컬 SQLite의 `review_groups`에 저장하고, 기존 YAML의 4개 기본 그룹으로 최초 한 번만 초기화. 모두 삭제해도 재시작 시 되살아나지 않음.
- 저장과 제안 재분류는 별개. `현재 초안에 분류 제안 다시 계산`을 눌러 **해당 미확정 회차에만** 새 규칙 적용. 기존 원본, 수록 여부, 수동 섹션·제목·요약, 확정본은 변경하지 않음.
- 추천 그룹은 **키워드 기반 규칙 제안**을 구성하는 것이며, GPT API 분석은 기존대로 별도 수행. 키워드가 일치한다는 사실을 원문 관련성 검증으로 표시하지 않음.
- 뉴스레터 892호의 섹션/템플릿 구조는 그대로 유지. 사용자가 만든 그룹은 반드시 4개 출력 섹션 중 하나에 매핑.

## 검사한 경계
- 그룹 0건·삭제/수정/재시작·중복 그룹명·잘못된 섹션·과도한 키워드 수는 검증.
- GLP-1 치료제 **시장**이라는 직접 신호가 연구개발 키워드보다 우선하도록 기존 강화 키워드 점수 유지.
- API 변경은 로컬 토큰·Origin·Host 검사 안에서만 허용. 서버는 로컬 127.0.0.1에서만 수신.
- 수집 커버리지와 GPT 실호출, 실제 208건과 이메일 클라이언트 렌더링은 이번 변경 범위에 포함되지 않음.
