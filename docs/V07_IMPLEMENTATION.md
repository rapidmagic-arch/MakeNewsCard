# MakeNewsCard v0.7 통합 구현 검토

## 목표
수집 원본 → GPT/규칙 제안 → 담당자 검토 → 회차 확정 → 보존 HTML 도서관. 자동 발송 없음.

## 체크리스트
- [x] .env.example 및 python-dotenv. OS 환경변수가 우선이고 비밀키는 API 응답에 노출하지 않음
- [x] 도서관 확정본 읽기 전용 열람, 검색, 12개씩 페이지 이동
- [x] 기사 검토/미리보기 회차 변경 대화상자. 환경설정과 대시보드에서는 선택 콤보 제거
- [x] 목록·카드 선택형 탐색, 카드의 상세 검토 및 원문 보기
- [x] 장문 링크 제목을 검증 대기로 분류, 자동 추천 제외, 앵커 원본 보존
- [x] 기존 원본, 담당자 선택, 확정 HTML 스냅샷 변경 없음

## 상호영향
- 아카이브 GET은 현재 편집 회차를 전환하지 않음. 초안 이어 편집/회차 변경이 명시적 전환
- 오래된 장문 제목은 원본을 임의 수정하지 않고 검증 표시만 함
- 이메일 렌더러/892호 템플릿 변경 없음. 편집 UI CSS만 추가
- .env는 허용된 공개 정적 경로로 제공하지 않음. 서버 재시작 후 API 설정 반영

## 미반영 및 검증 대기
- 사이트별 메뉴 자동 탐색, 개별 사이트 전문 파서, 공식 API/RSS 교차검증
- 사용자의 Windows 실제 DB와 실사이트 데이터 정확도, 유료 OpenAI API 실호출
- Outlook 등 이메일 클라이언트 검증 및 실제 발송
