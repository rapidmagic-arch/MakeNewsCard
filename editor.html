기사 검토 작업대

추천을 먼저 확인하고, 필요한 기사만 추가 선택한 뒤 수록 목록에서 최종 편집해.

회차에 연결된 기사만 조회해. 미확인 날짜와 수집 범위를 확인해.

1. 추천 후보 분석

원본 제목·메타데이터를 분석해 추천과 분류를 제안해. 결과는 수록 확정이 아니야.

뉴스레터 미리보기·확정

최종 확정 시 현재 기사 선택과 HTML을 보존해. 확정 후에는 수정할 수 없으며, 메일 발송은 수행하지 않아.

회차 최종 확정

환경설정

추천 그룹을 추가·수정·삭제하고, 각 그룹의 키워드와 발행 분야를 지정해. 최종 수록 여부는 기사 검토에서 사람이 결정해.

추천 그룹 관리

예: 보험·약가 → 정책, ADC 연구 → 연구개발. 추천 그룹은 후보 분류용이며 뉴스레터의 4개 발행 섹션은 그대로 유지해.

추천 그룹 추가

그룹 변경은 기존 기사와 담당자 선택을 삭제하지 않아. 다시 계산을 누르면 미확정 회차의 규칙 제안만 갱신해.

수집원 및 API 상태

수집원 URL과 추가 점수 설정은 현재 YAML 파일에서 관리해.
